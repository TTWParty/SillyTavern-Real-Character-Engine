# 拟真角色模拟引擎 (SillyTavern Real Character Simulation Engine)

一款为 SillyTavern 打造的全套拟真人类认知与神经模拟引擎扩展。彻底接管酒馆对话生成，以 12 层认知模拟系统驱动 NPC 的真实心理运作，拒绝机械迎合、设定遗忘与单调冗长独白。

---

## 核心设计与拟真机制

本扩展并非简单的提示词填充或浮动界面挂件，而是将完整的认知神经模拟系统深度接入 SillyTavern：

1. **System 1 (SemIf) 潜意识与瞬时微反应**：
   - 毫秒级本能偏向判定（接近 / 回避 / 戒备 / 审视 / 顺从）。
   - 具身微动作与生理直觉（如瞳孔收缩、指尖收拢、喉部微紧），先于意识产生。

2. **认知聚光灯与米勒定律工作记忆限制 (7±2 / 4 槽位)**：
   - 彻底打破大模型全知全能的上帝视角。
   - 角色注意力聚光灯同时仅能锁定 1 个主焦点与最多 4 个工作记忆槽位。超出容量的边缘信息无法进入当前视野。

3. **动态危机目标替换 (Dynamic Crisis Goal Substitution)**：
   - 处于平稳状态时推进既定日常目标；一旦检测到底线触碰或关系危机，聚光灯瞬间劫持，日常目标强制冻结，优先执行防御或反击对策。

4. **死话题冷酷剔除账本 (Topic Retirement Ledger)**：
   - 双方已达成共识、确认终结或因伤害而退役的话题，从上下文组装包中彻底抹除。大模型在底层完全接收不到退役词眼，杜绝原地踏步的车轱辘话。

5. **关系张力与怨念累积 (Relational Stance & Resentment)**：
   - 跟踪信任度、喜爱度、支配度与怨念值。
   - 伤害产生后怨念值持续维持，必须经历实质性补救试炼才能化解，绝不因虚假道歉瞬间和解。

6. **微信式连发气泡打字节律 (Burst Messaging)**：
   - 告别传统 AI 吐出一整堵小说式大段文字的虚假感。
   - 模拟真人聊天时连发 2-3 个气泡，各气泡之间伴随真实的思考与打字延迟。

7. **脱机自主意识心跳 (Autonomous Mind Pulse)**：
   - 角色具备内在动机与脱机节律。在玩家沉默或离线时，可在后台自动评估场景与动机，主动发起搭话或完成动作。

8. **实时认知聚光灯悬浮监视器 (Cognitive Telemetry HUD)**：
   - 在酒馆聊天窗口提供通透的玻璃拟态悬浮面板，实时可视化显示角色的注意力焦距、工作记忆槽位、PADS情感向量、微反应和关系张力。

## 安装方法

### 方式一：软链接安装 (推荐开发与本地使用)

将本扩展目录软链接至 SillyTavern 的第三方扩展目录中：

```bash
# 进入 SillyTavern 的第三方扩展目录
cd /path/to/SillyTavern/public/scripts/extensions/third-party/

# 创建软链接指向本仓库
ln -s /Users/ttwp-09/ALL/CODE/SillyTavern-Real-Character-Engine Real-Character-Engine
```

### 方式二：手动复制安装

将当前目录直接复制或解压到：
`/path/to/SillyTavern/public/scripts/extensions/third-party/Real-Character-Engine`

重启 SillyTavern 或刷新浏览器页面即可在扩展抽屉中看到「拟真角色模拟引擎」。

## 后端引擎配置与启动

本扩展依赖本地认知模拟后台服务。在项目根目录启动服务：

```bash
cd /Users/ttwp-09/ALL/CODE/WEBALL-HARNESS

# 确保本地 PostgreSQL 数据库已启动 (默认端口 5432)
# 启动 Fastify 模拟 API 服务 (默认监听端口 4000)
pnpm --filter @rp/api dev
```

验证后端健康状态：
```bash
curl http://127.0.0.1:4000/health
# 期望返回: {"ok":true,"service":"api"}
```

## 双轨接管模式 (Dual Takeover Modes)

### 轨道一：扩展原生全权接管模式 (推荐体验)

1. 打开 SillyTavern 顶栏的 **扩展插件 (积木图标)**。
2. 展开 **拟真角色模拟引擎 (Real Character Engine)** 设置面板。
3. 开启 **「全套拟真引擎接管对话生成」** 主开关。
4. 确保服务地址为 `http://127.0.0.1:4000`，点击 **「测试服务连通性」** 确认显示在线。
5. 开启 **「微信式连发气泡打字节律」** 与 **「显示聊天悬浮认知面板」**。
6. 在酒馆输入框像平时一样输入消息并发送。扩展将完全拦截默认生成流程，由 12 层认知模拟引擎驱动分段气泡打字，并在悬浮 HUD 中实时更新角色的内心世界。

### 轨道二：OpenAI 兼容中转代理模式 (无缝替代)

如果你希望保留 SillyTavern 原生生成快捷键与流式响应机制：

1. 打开 SillyTavern 的 **API 连接设置** (电源图标)。
2. API 类型选择 **Chat Completion**。
3. 服务商选择 **Custom (OpenAI-compatible)**。
4. 接口地址填入：`http://127.0.0.1:4000/v1`。
5. 模型选择：`rp-real-character-engine`。
6. 点击连接。SillyTavern 的每一次请求都会直接穿透至认知模拟核心进行全套推演。

## 悬浮认知监视器功能速查

悬浮在聊天窗口的 Cognitive HUD 实时展示以下维度：

- **System 1 潜意识微反应**：显示神经系统的直觉反应（如「眼神游移」、「呼吸微滞」）、语调（gentle / urgent / confrontational）与压力等级。
- **注意力焦距 (Salience %)**：认知聚光灯当前对该议程的聚焦饱和度。
- **工作记忆槽位 (4 槽位)**：米勒定律记忆槽位的占用情况，直观呈现信息超载状态。
- **PADS 动力学情感向量**：愉悦度 (Pleasure)、激活度 (Arousal)、支配度 (Dominance)、安全感 (Safety)、抑制力 (Inhibition)。
- **人际动力学计量条**：信任、喜爱、亲密度，以及关键的怨念累积警戒条。
- **人格面具与失调泄漏**：指示角色是否处于面具防御状态，以及是否存在微反应与真情实感的泄漏风险。

## 常见问题排查

1. **测试连通性显示离线？**
   - 检查 Fastify API 是否在 4000 端口运行：`lsof -i :4000`。
   - 检查 PostgreSQL 数据库是否正常运行：`lsof -i :5432`。
   - 检查控制台网络请求是否存在跨域或端口占用冲突。

2. **气泡连发速度过快或过慢？**
   - 在扩展设置面板中拖动「气泡打字速度倍率」滑块（0.5x 至 2.0x）微调延迟节奏。

3. **如何重置角色记忆？**
   - 点击设置面板中的「立即同步当前角色」按钮，强制将当前卡面基线重新写入后端认知数据库。
